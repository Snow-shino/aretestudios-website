title: Hitboxes, Hurtboxes, and Sockets
description: Use Aseprite marker layers to create PaperSprite sockets and optional Blueprint-readable HIT/HURT data.
---

Ase2UE can read simple marker layers from Aseprite.

The most common use is creating PaperSprite sockets for hands, weapons, feet, or trace points.

## Supported Layer Names

Use these prefixes:

```text
SOCKET
HIT
HURT
```

Examples:

```text
SOCKET_Hand
SOCKET_WeaponTip
HIT_WeaponStart
HIT_WeaponTip
HURT_Body
```

## Create A Socket

1. Create a new layer in Aseprite.
2. Name it something like `SOCKET_Hand`.
3. Place one visible 1x1 pixel where the socket should be.
4. Put the marker on the correct frame.
5. Save the Aseprite file.
6. Reimport in Unreal.

Ase2UE hides marker layers from the generated texture and writes matching sockets onto generated PaperSprites.

## Does Marker Color Matter?

No.

Ase2UE reads visible non-transparent pixels. Red, green, blue, white, and other colors all work.

Use color only for your own organization.

## Best Socket Settings

For exact socket placement, use Grid mode.

Set the grid cell size to your Aseprite canvas size.

```text
Aseprite canvas: 80 x 80
Sprite Extraction: Grid
Grid Cell Width: 80
Grid Cell Height: 80
```

## Why Socket Numbers Look Different

Aseprite shows pixel coordinates from the top-left of the canvas.

PaperSprite sockets are stored relative to the sprite pivot.

That means the Unreal socket transform will not match the Aseprite pixel number exactly. The visual socket location should still line up on the sprite.

## Weapon Trace Example

Create two marker layers:

```text
HIT_WeaponStart
HIT_WeaponTip
```

After import, use those socket locations as your trace start and trace end.

## Optional Hitbox Data Asset

The default workflow is socket-first.

If you want Blueprint-readable HIT, HURT, and SOCKET data grouped by animation frame, enable:

```text
Generate Hitbox Data Asset
```

This is optional and more advanced. Most users can leave it off.
