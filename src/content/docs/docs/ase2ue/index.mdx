Ase2UE imports saved Aseprite files into Unreal Engine Paper2D projects.

Click **Import Now** and Ase2UE can create:

- A spritesheet texture
- PaperSprite assets
- PaperFlipbooks from Aseprite tags
- PaperSprite sockets from marker layers

Ase2UE is an editor tool. It does not import files at runtime.

## Start Here

Most users should use this setup:

```text
Sprite Extraction: Grid
Grid Cell Width: your Aseprite canvas width
Grid Cell Height: your Aseprite canvas height
```

Example:

```text
Aseprite canvas: 384 x 224
Grid Cell Width: 384
Grid Cell Height: 224
```

Use Grid mode for characters, animations, and sockets.

## Quick Import Steps

1. Enable **Paper2D**.
2. Enable **Ase2UE**.
3. Set your Aseprite path in `Project Settings > Plugins > Ase2UE` if needed.
4. Create an **Ase2 Source** asset.
5. Pick your `.ase` or `.aseprite` file.
6. Pick an import folder under `/Game`.
7. Use **Grid** and set the grid size to your canvas size.
8. Click **Import Now**.

## Reimport Workflow

1. Edit your art in Aseprite.
2. Save the file.
3. Return to Unreal.
4. Click **Import Now** again.

Ase2UE updates the same generated assets in place.

## Sockets From Marker Layers

To create a socket:

1. Add a new layer in Aseprite.
2. Name it `SOCKET_Hand`, `SOCKET_WeaponTip`, or another `SOCKET_` name.
3. Put one visible 1x1 pixel where the socket should be.
4. Save and reimport.

The marker pixel color does not matter. It only needs to be visible and not transparent.

## What Ase2UE Does Not Do

Ase2UE does not:

- Include Aseprite
- Import files at runtime
- Create gameplay, combat, or animation Blueprint logic
- Watch files live in the background
- Replace Aseprite

It focuses on making Aseprite-to-Paper2D asset importing faster and easier to repeat.
