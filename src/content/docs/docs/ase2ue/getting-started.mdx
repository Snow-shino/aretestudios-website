title: Getting Started

---

Ase2UE is an Unreal Engine editor plugin for importing Aseprite art into Paper2D.

It creates Unreal assets in the editor. It is not a runtime importer.

## Requirements

- Unreal Engine 5.5, 5.6, 5.7, or 5.8
- Paper2D enabled
- Aseprite installed locally
- A saved `.ase` or `.aseprite` file

## Install

1. Add the `Ase2UE` plugin folder to your project's `Plugins` folder.
2. Open your Unreal project.
3. Open **Edit > Plugins**.
4. Enable **Paper2D**.
5. Enable **Ase2UE**.
6. Restart Unreal if prompted.

## Set The Aseprite Path

Open:

```text
Project Settings > Plugins > Ase2UE
```

Set **Aseprite Executable Path** if Ase2UE does not find Aseprite automatically.

Common Windows paths:

```text
C:/Program Files/Aseprite/Aseprite.exe
C:/Program Files (x86)/Steam/steamapps/common/Aseprite/Aseprite.exe
```

## Import Your First File

1. In the Content Browser, create an **Ase2 Source** asset.
2. Open the **Ase2 Source** asset.
3. Set **Aseprite File** to your `.ase` or `.aseprite` file.
4. Set **Import Destination** to a folder under `/Game`.
5. Use **Sprite Extraction: Grid** for most character, animation, and socket workflows.
6. Set **Grid Cell Width** and **Grid Cell Height** to your Aseprite canvas size.
7. Click **Import Now**.

Example:

```text
Aseprite canvas: 384 x 224
Sprite Extraction: Grid
Grid Cell Width: 384
Grid Cell Height: 224
```

## What Gets Created

For `Player.aseprite`, Ase2UE creates assets like:

```text
/Game/YourFolder/Player/
  Textures/T_Player_Sheet
  Sprites/SP_Player_0000
  Flipbooks/FB_Player_Idle
```

The exact assets depend on your file, tags, and settings.

## Reimport

1. Edit your file in Aseprite.
2. Save the file.
3. Return to Unreal.
4. Click **Import Now** again.

Ase2UE updates the same generated assets in place.
