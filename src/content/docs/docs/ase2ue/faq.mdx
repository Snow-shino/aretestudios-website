## Is Ase2UE a runtime importer?

No. Ase2UE is an editor plugin. It creates and updates Unreal assets inside the editor.

## Does Ase2UE require Paper2D?

Yes. Ase2UE creates PaperSprites and PaperFlipbooks.

## Does Ase2UE include Aseprite?

No. Aseprite is not included.

Ase2UE uses your local Aseprite installation to export temporary PNG and JSON files during import.

## Aseprite was not found. What do I do?

Open:

```text
Project Settings > Plugins > Ase2UE
```

Set **Aseprite Executable Path** to your local `Aseprite.exe`.

## My imported texture is one extremely long row.

Update to the newest Ase2UE build.

Then use Grid mode and set the grid size to your Aseprite canvas size.

Example:

```text
Aseprite canvas: 384 x 224
Sprite Extraction: Grid
Grid Cell Width: 384
Grid Cell Height: 224
```

## My sockets do not appear.

Check:

- **Import Marker Layers** is enabled.
- The layer name starts with `SOCKET`, `HIT`, or `HURT`.
- The marker pixel is visible.
- The marker pixel is not transparent.
- The marker exists on the correct frame.
- Use a 1x1 marker for point-style sockets.
- Use Grid mode for exact placement.

## My socket position looks offset.

Unreal stores PaperSprite sockets relative to the sprite pivot.

Aseprite shows pixel coordinates from the top-left of the canvas.

The numbers can look different, but the socket should visually line up on the sprite.

## Flipbooks were not created.

Check:

- **Create Flipbooks From Tags** is enabled.
- Your Aseprite file has frame tags.
- Tags have clear names such as `Idle`, `Run`, or `Attack`.

## Marker pixels appear in the generated texture.

Use supported layer prefixes:

```text
SOCKET_Hand
HIT_WeaponTip
HURT_Body
```

Save the Aseprite file and reimport.

## What should I include in a support request?

Include:

- Unreal Engine version
- Aseprite version
- Ase2UE version
- Grid or Auto extraction mode
- Grid cell size if using Grid
- Screenshot of Ase2 Source settings
- Screenshot of Aseprite layers and tags
- Import report text
