This page explains the most important settings on an **Ase2 Source** asset.

## Aseprite File

Choose the `.ase` or `.aseprite` file to import.

If the file picker looks empty, switch it to all files or paste the full path.

## Import Destination

Choose where generated assets go.

Use a folder under `/Game`.

Good:

```text
/Game/Sprites/Hero
```

Not good:

```text
C:/Art/Hero
```

## Recommended Mode: Grid

Use **Grid** for most imports.

Grid mode cuts the generated spritesheet into fixed-size cells. Set the cell size to your Aseprite canvas size.

Examples:

```text
Aseprite canvas: 80 x 80
Grid Cell Width: 80
Grid Cell Height: 80
```

```text
Aseprite canvas: 384 x 224
Grid Cell Width: 384
Grid Cell Height: 224
```

Use Grid when:

- Every frame uses the same canvas size.
- You want predictable sprite bounds.
- You are importing sockets or marker layers.
- You want the safest reimport workflow.

## Auto From Aseprite JSON

Auto mode reads frame rectangles from Aseprite's exported JSON.

Use Auto when:

- Frames are packed or trimmed.
- You do not need exact socket marker placement.
- You want Aseprite's exported frame rectangles to drive sprite bounds.

If sockets look wrong in Auto mode, switch to Grid.

## Pivot Mode

The PaperSprite pivot applied to every generated sprite.

Common choices:

- **Center Center** for characters.
- **Bottom Center** for grounded actors.

## Default Material

The material applied to generated sprites.

The default uses Paper2D's masked lit sprite material. You can switch to an unlit Paper2D material if your project does not use sprite lighting.

## Flipbooks From Tags

If **Create Flipbooks From Tags** is enabled, Ase2UE creates one PaperFlipbook for each Aseprite tag.

Example:

```text
Idle -> FB_Player_Idle
Run -> FB_Player_Run
Attack -> FB_Player_Attack
```

## Frame Timing

Enable **Use Aseprite Frame Durations** if you want Unreal flipbooks to use the timing from Aseprite.

Disable it if you want all frames to use the **Flipbook Frames Per Second** value.

## Import Report

After import, Ase2UE shows:

- **What was done**: successful actions.
- **Notes**: helpful information.
- **Warnings**: things that need attention.
